Sigma · Your documents

  • Runs where your data lives

    Sigma queries your warehouse directly. On OAuth connections, the row-level rules already set in your data platform still apply.

  • Permissions follow the person

    Row-level and column-level security hold in every workbook, application, Sigma agent, and Assistant answer. Claude, Codex, and ChatGPT get each user’s own Sigma permissions through the Sigma MCP server.

  • Every change is on record

    Audit logs capture user activity, Assistant and agent conversations, and API calls, including those from the Sigma MCP server. Version tags control which version goes live.
