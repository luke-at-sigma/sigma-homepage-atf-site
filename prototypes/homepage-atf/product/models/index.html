Data models FAQ

  • What is a data model in Sigma?

    A data model is a shared set of tables, relationships, and metric definitions that workbooks, apps, and agents read from, so everyone uses the same logic.

  • Do we have to rebuild our semantic layer?

    No. Sigma queries dbt Semantic Layer metrics, and Snowflake semantic views and Databricks metric views are in beta.

  • Where does the logic run?

    In your warehouse. Sigma pushes queries down to it instead of computing in a separate engine.

  • How do AI answers use the model?

    Sigma Assistant and Sigma Agents answer from the governed model, so their numbers match your dashboards.
