Sigma agents FAQ

The questions worth asking before putting AI agents on your data.

  • What is a Sigma agent?

    A Sigma agent is an AI agent your team builds in plain language on live data in your data warehouse. It can answer questions or run on a schedule, and it can write back or call other systems within the user’s permissions.

  • How is a Sigma agent different from a BI copilot?

    A copilot answers the question and stops. A Sigma agent can also take the next step, like writing back or opening a ticket, with a person’s sign-off if you want one.

  • Which AI model runs our agents?

    Your admins choose the AI provider as an org setting, with options in Databricks, Gemini, OpenAI, and Snowflake. Agent queries run on your data warehouse compute either way.

  • Can we start with human approval and move to autonomy later?

    Yes. Most teams start in chat with approval on every change, then move an agent onto a schedule once its output holds up.

  • Do Sigma agents work with Claude or ChatGPT?

    Yes, and many teams use both. The Sigma MCP server lets Claude and ChatGPT find the workbooks and data models your team already built and query them through each person’s Sigma login.

  • What does an agent cost to run?

    Agents use consumption credits. Admins see questions, active users, and token usage for every agent over the last 7 to 90 days, and can sort to find the highest-cost agents.
